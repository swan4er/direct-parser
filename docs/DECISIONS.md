## Решения

## D-1. Запуск через python и requirements.txt (15.10.2026)
**Вопрос:** запускать программу через uv или обычным Python.
**Варианты:** uv с зависимостями в шапке файла — одна команда, но нужен uv; python и requirements.txt — стандартно, работает на Windows без лишних инструментов; оба списка сразу — со временем разъедутся.
**Выбрано:** основной запуск — `python main.py` и `requirements.txt`; uv — необязательный вариант через `--with-requirements`.
**Почему:** «давай основной вариант запуска без uv», «почему нет requirements.txt?»; программу будут запускать не только через агента.
**Почему должно работать:** установщик Python с python.org ставит pip; список зависимостей один.
**Влияет на:** README, requirements.txt, начало main.py, автоустановку библиотек.
**Статус:** действует.

## D-2. Регион показа задаёт параметр lr (15.10.2026)
**Вопрос:** от чего зависит, объявления какого региона показывает yandex.ru/search/ads.
**Варианты:** от IP посетителя (гипотеза агента — оказалась неверной); от параметра `lr` в адресе.
**Выбрано:** регион задаётся `lr`, IP не учитываем.
**Почему:** «изучи документацию — там регион указывается квери-параметром», «у меня тоже айпишник не российский».
**Почему должно работать:** замер 15.10.2026: с малайзийского IP `lr=2` дал объявления именно по Петербургу.
**Влияет на:** параметр `-r`, вопрос о городе, справочник REGIONS.
**Статус:** действует.

## D-4. Прогоны: по умолчанию 1, максимум 10 (15.10.2026)
**Вопрос:** повторять ли сбор ради полноты (Яндекс каждый раз показывает разный набор) и сколько раз максимум.
**Варианты:** один прогон — быстро, но это выборка; несколько с объединением — полнее и дольше; максимум выбрать по замеру насыщения.
**Выбрано:** по умолчанию 1 прогон, число настраивается; максимум 10 агент предложил по замеру, Станислав не возражал.
**Почему:** «по умолчанию 1 прогон с возможностью настроить. Максимальное число нужно подумать какое».
**Почему должно работать:** замер 10 прогонов подряд: новые рекламодатели приходят во 2–6 прогонах, после 6-го — по одному или ни одного.
**Влияет на:** `--runs`, карточку ручного режима, collect().
**Статус:** действует. Открыт вопрос: 3 прогона по умолчанию в ручном режиме.

## D-5. Результаты по умолчанию — в папке results (15.10.2026)
**Вопрос:** куда сохранять результат, если путь не указан.
**Варианты:** в текущую папку, как было; в папку results рядом с программой.
**Выбрано:** `results/ads_<дата>_<время>.xlsx` рядом с программой; явный `-o` считается от текущей папки.
**Почему:** «давай сохранять результат в папке results».
**Почему должно работать:** результаты собираются в одном месте, откуда бы ни запустили программу; агент получает ровно тот путь, который указал.
**Влияет на:** default_output(), .gitignore, пункт «Файл» в карточке.
**Статус:** действует.

## D-6. Цветной текст в терминале (15.10.2026)
**Вопрос:** сделать ли вывод цветным.
**Варианты:** коды цвета вручную и включение режима VT в консоли Windows — без зависимостей; colorama — ещё одна библиотека; rich — тяжёлая библиотека ради цвета.
**Выбрано:** цветной текст; реализацию без библиотек выбрал агент.
**Почему:** «можем текст сделать цветным? в терминале».
**Почему должно работать:** цвет только в настоящем терминале, переменная NO_COLOR его выключает; если на Windows включить цвет не удалось — вывод без цвета. Строки ввода без цвета: с readline цветные приглашения выводятся мусором.
**Влияет на:** paint(), log(), say().
**Статус:** действует.

## D-7. Публичный репозиторий, Windows проверяет Станислав (15.10.2026)
**Вопрос:** как проверить программу на Windows, если у агента её нет.
**Варианты:** приватный репозиторий и автоматические тесты на Windows в GitHub Actions; Станислав запускает сам.
**Выбрано:** публичный репозиторий github.com/swan4er/direct-parser; на Windows проверяет Станислав.
**Почему:** «проверю на винде сам. Просто запушь в публичный репозиторий».
**Почему должно работать:** настоящие сценарии на настоящей Windows проверяют то, что не проверить на Linux: консоль, двойной щелчок, кодировки.
**Влияет на:** процесс: проверенные изменения публикуются в ветку main.
**Статус:** действует.

## D-8. Ручной режим: два вопроса и карточка (15.10.2026)
**Вопрос:** ревью глазами новичка (24 пункта) показало, что пять вопросов подряд сложны, а данные теряются; как перестроить ручной режим.
**Варианты:** А — подлатать пять вопросов: быстро, но без возврата назад; Б — два вопроса и карточка с правкой любого пункта; В — меню со стрелками (questionary): новая зависимость, потерю данных не решает.
**Выбрано:** Б.
**Почему:** «Я выбираю вариант Б»: новичку хватает двух ответов и Enter, время видно до старта, пункт меняется без перезапуска.
**Почему должно работать:** проверено в настоящем терминале 80×24 с живым Яндексом; тесты на каждый пункт ревью.
**Влияет на:** interactive() и его тесты; общее ядро надёжности (капча, связь, Ctrl+C, сохранение по ходу) — для обоих режимов.
**Статус:** действует.
