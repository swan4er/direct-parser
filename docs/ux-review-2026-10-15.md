# Пошаговый режим глазами новичка — разбор 15.10.2026

Что проверялось: `python main.py` без аргументов (пять вопросов), коммит `492d5f2`.
Код не менялся, прогон шёл на копии `main.py`.

## Кто «пользователь»

Маркетолог, терминал открывает впервые. Читает только то, что на экране, в README не заглядывает.
Опечатки исправляет стрелками, список запросов вставляет из заметок, сами запросы держит в Excel.
На непонятный вопрос отвечает как понял («2 страницы», «3-5», «Ставропольский край»),
в остальных местах жмёт Enter.

## Как проверял

- Отдельный сервер tmux (`tmux -L dumbuser`), чужие сессии не задеты. Окно 80×30 и 100×30.
  Ввод — `send-keys -l`, вставка — `paste-buffer`, экран — `capture-pane -p -S -1000`.
- Настоящий Яндекс — 14 обращений (10:08–10:19 МСК).
- «Нет интернета» — недоступный прокси: `HTTPS_PROXY=http://127.0.0.1:9`.
- Капча и «новая вёрстка» — обёртка, которая подменяет `main.BASE_URL` на локальный
  `python -m http.server`. Для капчи сервер отдаёт страницу со ссылкой `/checkcaptcha`,
  для новой вёрстки — страницу без объявлений и без пометки «ничего не нашлось».
- Стрелки на macOS: `script -q /dev/null python3 -c 'print(repr(input()))'` на маке,
  ввод подаётся через псевдотерминал.
- Windows не проверялась.

## Список улучшений

Важность: 4 — теряются данные или уходит мусор; 3 — человек застрянет или сделает не то;
2 — неудобно; 1 — косметика.

### Теряются данные или уходит мусор

1. **(4) Стрелки ломают запрос.** Коды клавиш попадают в запрос и уходят в Яндекс. В конце
   программа падает на записи Excel, и весь сбор пропадает. Проверено на Linux и на macOS;
   в консоли Windows стрелки, по её устройству, должны работать — не проверял.
   Исправление: `import readline` на macOS/Linux (на Windows этого модуля нет — `try/except ImportError`).
   Подстраховки: вычищать управляющие символы из всех ответов; перед записью убирать символы,
   недопустимые в Excel; если файл не записался, сохранять запасной JSON, а не трейсбек.
2. **(4) Excel со списком запросов превращается в мусор.** Из байтов архива получаются
   сотни «запросов», они уходят в Яндекс (риск капчи), потом падает запись (как в п. 1).
   Варианты: читать первую колонку `.xlsx` (openpyxl уже в зависимостях) / только отказывать
   с подсказкой «сохраните как .txt». Остальные двоичные файлы отличать по нулевым байтам
   и сигнатуре `PK\x03\x04` и отказывать с понятным текстом.
3. **(4) Молча перезаписывается файл.** Неудачный сбор затирает прошлый удачный файл с тем же
   именем. Исправление для пошагового режима: существующее имя → `отчёт (2).xlsx` с сообщением.
   Пустой результат, если все обращения кончились ошибкой, поверх файла не писать.
4. **(4) Ctrl+C посреди сбора — всё пропадает,** и программа об этом не сообщает.
   Исправление: при Ctrl+C сохранять собранное; а лучше переписывать файл после каждого прогона —
   тогда уцелеют и уже пройденные прогоны, если окно просто закрыли.
5. **(3) Провал выглядит как успех.** Нет сети, капча или непонятная страница — в конце всё равно
   зелёное жирное «Готово: … объявлений 0». Исправление: итог по исходу — зелёный «готово»,
   жёлтый «собрано частично» или красный «не получилось», с причиной и подсказкой, что делать.

### Шаг 1 — запросы

6. **(3) После запроса и Enter ничего не происходит.** Приглашения ко вводу нет, и не видно, что
   программа ждёт ещё строку. Слова «в конце пустая строка» новичок не понимает. После вставки
   списка нужен ещё один Enter, а то и два. Исправление: нумерованное приглашение `1>`, `2>`;
   на пустой строке — показать список и подпись «Enter — дальше, или допишите ещё».
7. **(3) Пустая строка внутри вставленного списка обрывает ввод,** хвост списка уходит в вопрос
   о регионе. Исправление — подтверждение из п. 6: всё, что пришло после пустой строки, добавляется
   к списку. Отвергнутые варианты: заканчивать ввод двумя пустыми строками (новичок не догадается);
   ловить вставку по уже пришедшим строкам (`select`/`msvcrt` — свой код под каждую систему).
8. **(3) Опечатка в пути к файлу молча становится поисковым запросом.** То же с `queries.txt`,
   если программа запущена не из своей папки. А имя для сохранения, наоборот, отсчитывается
   от папки программы. Исправление: строка похожа на файл (есть `/`, `\` или окончание
   .txt/.csv/.xlsx), а файла нет — предупредить; искать файл и в текущей папке, и рядом с программой.
9. **(2) Запросы через запятую склеиваются в один.** Исправление: спросить «Разделить на 3 запроса?».

### Шаг 2 — регион

10. **(3) Не принимаются «Ставропольский край» и даже «36 Ставрополь» — ровно в формате подсказки.**
    В ответ только ссылка, а в cmd по ней не щёлкнешь. Исправление: брать число из «36 Ставрополь»;
    предлагать похожий город через `difflib.get_close_matches` («Ставрополь (36)? Enter — да»);
    по «?» показывать список известных городов.
11. **(3) По Enter подставляется «Россия»,** хотя реклама сильно зависит от региона (так в README),
    а в моём прогоне регион по умолчанию дал пустые ответы (вывод слабый, см. выше). Решение за Станиславом.
12. **(2) Неизвестный код (999999) принимается без подтверждения.**

### Шаги 3–4 — страницы и прогоны

13. **(3) Подсказка «обычно хватает 3–5 прогонов», а по умолчанию 1.** Ответ «3-5» по подсказке —
    ошибка. Решение за Станиславом: что ставить по умолчанию.
14. **(2) «Сколько страниц» без ориентира.** «2 страницы» — ошибка. Исправление: брать число
    из ответа; подпись «обычно 1–2; кончится реклама — остановлюсь сам».

### Шаг 5 — файл

15. **(3) Перетащил папку — файл ложится рядом с ней под её именем.** Исправление: если указана
    папка, сохранять внутрь с именем по умолчанию.
16. **(2) В ошибке формата предлагается `'-'`, а в этом режиме он означает файл `-.xlsx`.**
    Убрать `'-'` из текста; добавить «Не знаете, что выбрать, — Excel».

### Перед стартом, во время сбора, в конце

17. **(3) Нет проверки перед стартом.** Время видно, только когда сбор уже пошёл. Назад не вернуться:
    Ctrl+C и ввод всех запросов заново. Исправление — карточка (см. «Каркас»).
18. **(3) Капча и незнакомая страница советуют флаги, которых в этом режиме нет,** а сбор при этом
    не останавливается. Исправление: человеческий текст; остановка после первой капчи с сохранением
    собранного; незнакомую страницу сохранять автоматически и просить отправить её разработчику.
19. **(3) Без сети на каждый запрос выводится стена служебного текста** (`%D0%BA…`, `ProxyError`)
    и ~7 с ожидания. Исправление: «Нет связи с Яндексом — проверьте интернет или VPN»;
    после 2–3 сетевых ошибок подряд — остановка.
20. **(2) В конце — длинный путь,** по которому в cmd не щёлкнешь. Исправление: предложить открыть
    файл или папку (`os.startfile` в Windows, `open -R` в macOS).

### Мелочи

21. (2) «Запросов: 1» — это фразы, «Запросов к Яндексу: до 6» — обращения. В README уже «обращений».
22. (1) Нет «Шаг 2 из 5» и одной строки о том, что получится в итоге.
23. (1) При ширине 80 колонок строки рвутся посреди слова («Вых|од», «Ставро|поль»).
    Исправление: `textwrap` под `shutil.get_terminal_size()`.
24. (2) Без библиотек: «Не установлена библиотека bs4. Выполните: pip install…» — непонятно, что такое
    bs4 и куда вводить команду. Исправление: предложить установить
    (`sys.executable -m pip install -r <requirements.txt рядом с программой>`).

### Что уже хорошо — не сломать

Значения по умолчанию в скобках; на неверный ввод программа переспрашивает, а не падает (кроме
стрелок); работает перетаскивание .txt с пробелом в имени; города понимаются без учёта регистра,
есть «питер» и «мск»; оценка времени точная; формат файла проверяется до начала сбора.

## Каркас: три варианта

Пункты 1–5, 18 и 19 нужны при любом каркасе. Это общий код, он полезен и режиму с параметрами.

- **А. Точечные правки в пяти вопросах.** Даёт: быстро и почти без риска. Запирает: пять вопросов
  подряд без возврата; каждая новая настройка (пауза от капчи, прокси) — ещё один вопрос.
- **Б. Два вопроса и карточка.** Спрашиваются только запросы и город, остальное показывается списком:
  «Enter — начать, номер — изменить пункт», с оценкой времени до старта. Даёт: новичку — два ответа
  и Enter; любой пункт меняется без перезапуска; новые настройки становятся строкой карточки;
  сюда же ложится «как в прошлый раз». Долг: переписать `interactive()` и его тесты.
- **В. Меню стрелками (questionary/prompt_toolkit).** Даёт: выбор стрелками. Запирает: новая
  зависимость; окно Windows при двойном щелчке нужно проверять отдельно; потерю данных, капчу
  и мусор из Excel не решает.

Рекомендация: Б.

## Не проверено

Windows: двойной щелчок, cmd, вставка правой кнопкой, имена файлов с `: ? * < > |`.
Последние проходят проверку `_prepare_output`, потому что новый файл там не создаётся, —
что сделает Windows при записи, не проверял.
