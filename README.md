# direct-parser

Собирает рекламные объявления Яндекс.Директа по поисковым запросам со страницы
`yandex.ru/search/ads`: домен рекламодателя, заголовок, описание, быстрые ссылки, позицию.
Сохраняет в Excel, CSV или JSON — по умолчанию в папку `results` рядом с программой.

## Установка

Нужен Python 3.10 или новее.

**Windows.** Поставьте Python с [python.org](https://www.python.org/downloads/), в установщике
отметьте «Add python.exe to PATH». Откройте папку программы в Проводнике, наберите `cmd`
в адресной строке и нажмите Enter. В открывшемся окне выполните:

```
py -m pip install -r requirements.txt
```

**macOS и Linux.**

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Если `python3 -m venv` ругается на `ensurepip`, в Debian и Ubuntu поставьте пакет
`python3-venv` или запускайте через uv (см. ниже).

Если библиотеки не установлены, ручной режим сам предложит их поставить и перезапустится.

## Ручной режим (для человека)

```
python main.py
```

На Windows — `py main.py` или двойной щелчок по `main.py`. Вопросов два:

1. **Запросы.** По одному на строку (строки пронумерованы), в конце пустая строка. Можно
   вставить список целиком или перетащить в окно файл: текстовый (запрос на строку) или
   таблицу Excel (запросы в первой колонке). Если запросы записаны через запятую,
   программа предложит их разделить.
2. **Город.** Обязателен: реклама сильно зависит от города. Название или код региона:
   «Москва», «Ставрополь», «36», «СПб»; вся страна — «Россия». На `?` показывается список
   городов, на опечатку — похожий город.
   [Все коды регионов](https://aistudio.yandex.ru/docs/ru/search-api/reference/regions).

Дальше — карточка: что будет собрано и сколько это займёт. Enter начинает сбор, цифра 1–4
открывает пункт для правки, 0 — выход:

```
Проверьте перед стартом:
  1. Запросы: 2 (купить духи, парфюм магазин)
  2. Город: Ставрополь (36)
  3. Полнота: прогонов — 3, страниц на запрос — 1
  4. Файл: results/ads_2026-10-15_08-20-19.xlsx
  Сбор займёт около 10 с, обращений к Яндексу — до 6.
Enter — начать, 1–4 — изменить пункт, 0 — выйти:
```

В пункте «Файл» можно ввести просто имя (файл ляжет в `results`), путь или папку. Уже
существующий файл не перезаписывается: результат сохранится как «имя (2).xlsx». В конце
программа предложит открыть таблицу. Вопросы «да или нет» задаются цифрами (Enter — да,
0 — нет), чтобы не зависеть от раскладки клавиатуры.

Собранное не пропадает: файл сохраняется после каждого запроса, а Ctrl+C останавливает
сбор и сохраняет то, что успели собрать.

## Запуск с параметрами (для скриптов и агента)

```bash
python main.py "купить духи" "парфюм магазин"            # → results/ads_<дата>_<время>.xlsx
python main.py -f queries.txt -p 2 -r Москва --runs 3 -o ads.xlsx
python main.py -f queries.txt -r 36 -o -                  # JSON в stdout
cat queries.txt | python main.py -f - -o ads.csv          # запросы из stdin
```

| Параметр | Что делает | По умолчанию |
|---|---|---|
| `QUERY …` | запросы аргументами | — |
| `-f FILE` | файл с запросами: текст (один на строку, `#` — комментарий, кодировка UTF-8, UTF-16 или cp1251 определяется сама), Excel `.xlsx` или CSV — первая колонка первого листа, заголовок «Запрос» пропускается; `-` — stdin | — |
| `-p N` | сколько страниц объявлений брать на запрос | 1 |
| `-r REGION` | регион: код (`213`) или название крупного города (`Москва`) | 225 (Россия) |
| `--runs N` | сколько прогонов сделать и объединить, от 1 до 10 | 1 |
| `-o PATH` | `.xlsx`, `.csv`, `.json` или `-` (JSON в stdout). Явный путь считается от текущей папки, существующий файл перезаписывается | `results/ads_<дата>_<время>.xlsx` рядом с программой |
| `--delay SEC` | пауза между обращениями к Яндексу | 1 |
| `--proxy URL` | прокси (`http://user:pass@host:port`); `HTTPS_PROXY` тоже работает | — |
| `--save-html DIR` | сохранять полученные страницы — пригодится, если Яндекс поменяет вёрстку | — |

Все подробности: `python main.py --help`. Перед сбором программа пишет, сколько будет
обращений к Яндексу и сколько примерно это займёт (около 1,7 с на обращение с паузой 1 с).

## Регионы

Регион уходит в параметр Яндекса `lr`. Программа понимает названия 61 крупного города
и 4 стран из [справочника Яндекса](https://aistudio.yandex.ru/docs/ru/search-api/reference/regions),
остальные регионы задаются числовым кодом из того же справочника.
Популярные коды: 225 — Россия, 213 — Москва, 1 — Москва и область, 2 — Санкт-Петербург,
54 — Екатеринбург, 43 — Казань, 35 — Краснодар, 36 — Ставрополь.

Объявления сильно зависят от региона. Замер 15.10.2026 по запросу «создание сайтов»:
Ставрополь, Краснодар, Казань и Новосибирск совпадают лишь на 28–42 % рекламодателей,
у местных студий свои поддомены под каждый город.

## Прогоны

Яндекс при каждом обращении показывает немного разный набор объявлений, поэтому один сбор —
выборка, а не полный список рекламодателей. Прогоны повторяют сбор и объединяют результаты:
одинаковые объявления (тот же домен, заголовок и текст) склеиваются, остаётся лучшая позиция,
а колонка «Встречалось в прогонах» показывает, как часто объявление попадалось. Каждый прогон
проходит все запросы, и только потом начинается следующий.

Замер 15.10.2026, 10 прогонов подряд: по «созданию сайтов» в Ставрополе за 10 прогонов нашлось
24 рекламодателя против 20 в первом, по «купить духи» по России — 17 против 10. Новые
рекламодатели приходят в основном во 2–6 прогонах, дальше — по одному или ни одного.
Поэтому обычно хватает трёх прогонов, а больше 10 программа не разрешает: прироста почти нет,
а нагрузка на Яндекс и риск капчи растут. В ручном режиме по умолчанию 3 прогона, в режиме
с параметрами — 1 (`--runs`).

## Что получается

- **Excel**: лист «Объявления» и лист «Запросы» со статусом каждого запроса и числом прогонов,
  в которых были объявления.
- **CSV**: только объявления, кодировка UTF-8 с BOM (Excel открывает кириллицу корректно).
- **JSON**: `{"region", "runs", "queries": [...], "ads": [...]}`.

Поля объявления: запрос, страница и лучшая позиция, в скольких прогонах встретилось, домен,
заголовок, описание, быстрые ссылки (в таблице через « | », в JSON списком), метка («Промо»),
ссылка.

**Ссылка — это счётчик кликов Яндекса (`yabs.yandex.ru/count/…`), а не адрес сайта.**
Переход по ней засчитывается рекламодателю как клик по объявлению, поэтому массово её
не открывайте. Сайт рекламодателя смотрите в поле «Домен».

## Если что-то пошло не так

- **Капча.** Яндекс решил, что запросов слишком много. Сбор останавливается сразу (дальше
  была бы только капча), собранное сохраняется. Подождите 15–30 минут и запустите снова.
- **Нет связи.** После трёх ошибок связи подряд сбор останавливается, собранное сохраняется.
  Проверьте интернет или VPN.
- **Незнакомая страница.** Похоже, Яндекс поменял вёрстку. Страница сохраняется в
  `results/debug` — по ней разработчик обновит разбор.
- **Файл не записался** (например, открыт в Excel). Собранное уходит в запасной файл
  `results/backup_<дата>_<время>.json`.

Итог в конце сбора говорит, что вышло: зелёный «Готово», жёлтый «Собрано частично»
или красный «Собрано не всё» и «Не получилось» — с причиной и подсказкой, что делать.

## Для агента

- Ручной режим включается, только если программа запущена без аргументов в терминале.
  Без терминала (агент, конвейер) вопросов не будет: нет запросов — выход с кодом 2.
- Данные идут в stdout только при `-o -`. Ход работы, итог с полным путём к файлу и ошибки
  пишутся в stderr. Вывод всегда в UTF-8, в том числе на Windows.
- Цвет включается, только когда вывод идёт в настоящий терминал; в перехваченном выводе
  цветовых кодов нет. Выключить цвет совсем: переменная окружения `NO_COLOR=1`.
- Статусы запросов: `ok` — объявления есть; `no_ads` — Яндекс ответил «ничего не нашлось»;
  `captcha` — капча; `unexpected` — незнакомая страница (похоже, поменялась вёрстка;
  путь к сохранённой странице — в `message`); `error` — ошибка связи; `skipped` — до запроса
  не дошли, сбор остановлен раньше.
- Коды выхода: `0` — есть объявления; `1` — капча, ошибка связи, незнакомая вёрстка или
  необработанные запросы (собранное всё равно сохраняется); `2` — неверные аргументы
  или результат некуда сохранить; `3` — ошибок нет, но объявлений ноль; `130` — остановлено
  по Ctrl+C, собранное сохранено.
- Файл из `-o` перезаписывается после каждого запроса: если процесс прервут, в нём останется
  собранное к этому моменту.

```bash
uv run --with-requirements requirements.txt main.py "купить духи"
```
